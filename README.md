RJ Mobility Analytics - Sistema de Analise de Mobilidade Urbana

Sobre o Projeto
Este projeto tem como objetivo consolidar, processar e analisar dados de mobilidade urbana e trânsito na cidade do Rio de Janeiro. Utilizando uma arquitetura moderna de engenharia de dados, a solução extrai informações de transporte, armazena-as de forma estruturada e disponibiliza indicadores visuais avançados para apoiar na tomada de decisões e na compreensão do fluxo urbano.

Tecnologias Utilizadas
O ecossistema do projeto foi construído com ferramentas focadas em alta performance e escalabilidade:

Python (ETL): Automatizacao da extracao, transformacao e carregamento de dados.

Docker e WSL2: Containerizacao do ambiente de banco de dados para garantir consistencia e portabilidade.

PostgreSQL: Armazenamento relacional robusto e otimizado para consultas complexas.

Power BI: Construcao do dashboard dinâmico e interativo para visualizacao de métricas e indicadores de desempenho.
